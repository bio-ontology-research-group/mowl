# `mowl.geometric` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `mowl.geometric` package that builds provably exact geometric models of EL++ ontologies (convex polyhedral, interval-union), checks region assignments against normalised axioms, diagnoses box-representability (Helly check) and searches for box models by MILP.

**Architecture:** A pure-Python ELK-style completion (ported from `moose/elpp/completion.py`) produces a finite `CanonicalModel` from mOWL's normalised axioms plus role axioms read from the OWLAPI ontology. Three model builders map the canonical model to regions (simplex faces, interval unions, boxes); a single `ModelChecker` decides axiom satisfaction exactly for each region family (combinatorially for intervals/boxes, by LP for polyhedra). Nothing is returned without passing the checker.

**Tech Stack:** Python ≥ 3.8 syntax (`from __future__ import annotations`), numpy, `scipy.optimize.linprog`/`milp` (HiGHS), JPype/OWLAPI through existing mOWL adapters, `unittest.TestCase` tests run with `pytest -m "not slow" -p no:faulthandler`.

**Spec:** `docs/superpowers/specs/2026-10-29-geometric-models-design.md` (v2). Read it first; this plan argues from it.

## Global Constraints

- No new mandatory dependency (numpy, scipy already in `install_requires`); `scipy.optimize.milp` needs scipy ≥ 1.9 — guard with `errors.MissingDependency` naming the version.
- Python 3.8-compatible syntax in library code (`from __future__ import annotations`; `typing.List/Dict/Tuple` in runtime positions).
- Every constructed model passes `ModelChecker.is_model(...)` before being returned; a failure raises `errors.InternalConsistencyError` (bug), never returns.
- Docstrings state the exact guarantee of each procedure (spec §5.3) and cite: Gutiérrez-Basulto & Schockaert KR 2018 Prop. 3/4; Lacerda, Ozaki, Guimarães TGDK 2024 Defs. 2, 12, Thms. 13, 25; Leemhuis & Kutz NeSy 2025 Defs. 3, 6, Props. 4, 5 and NAI 2026 Prop. 38; Federico, Leemhuis, Kutz JOWO 2026 Thm. 3; Kazakov, Krötzsch, Simančík JAR 2014; `moose/elpp` as the port source.
- Never write scratch files to `/tmp`; use `$TMPDIR` or `tests/geometric/_scratch` (gitignored).
- Work on branch `geometric-models`; commit after every task with the trailer `Claude-Session: https://claude.ai/code/session_01QpuQV4h67yVkBUhnyHLqBr`.
- Development environment: `~/.venvs/mowl-dev` (see `docs/superpowers/specs/env-setup-report.md`; if absent, create per spec §3). Run tests from the repo root: `~/.venvs/mowl-dev/bin/python -m pytest -m "not slow" -p no:faulthandler tests/geometric -q`.

## Review Focus

1. An inconsistent ontology (`⊤ ⊑ ⊥` derivable, e.g. `⊤ ⊑ A`, `A ⊑ ⊥`): every builder must raise `InconsistentOntology`, not return a model. Test in Task 2 (`test_inconsistent_raises`) and Task 5/6 (builders re-raise).
2. An ontology where every name is unsatisfiable except `⊤`: canonical model has one element; builders return a model with `η(A) = ∅` for all such `A`; `is_nondegenerate()` is `True` (no satisfiable name is empty). Test in Task 5 (`test_all_unsat_names`).
3. Axioms with `⊤` on the left (`⊤ ⊑ ∃r.B` from a range/domain axiom): must hold in both constructions because `η(⊤) = U`. Test in Task 6 (`test_top_on_lhs_gci2`) and Task 5.
4. Role chains longer than two and role inclusions: completion must respect them; `roles.owl` fixture has `r ∘ s ⊑ t` and `r ⊑ s`. Test in Task 2 (`test_role_chain_and_hierarchy`).
5. A name that occurs only in the OWL ontology but in no normalised axiom (isolated class): it must still be a canonical element with `A^I = {d_A}`, so `is_nondegenerate()` sees it. Test in Task 2 (`test_isolated_name_is_element`).

NF3 `A ⊑ ∃r.B`: for each vertex `v` of `η(A)`, feasibility of `μ` with `Σμ=1, μ≥0`, `first-half(μ·points) = v`, `second-half ∈ η(B)`.
